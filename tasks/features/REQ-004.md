# Goal

安装 TanStack Query，配置 Provider，并将 my-invest-global 前端的所有 API hooks 移植为 Next.js 兼容版本。

# In Scope

- **依赖安装**：`@tanstack/react-query`, `@tanstack/react-query-devtools`
- **新建**：`app/providers.tsx` — 包含 `QueryClientProvider`（`'use client'`）
- **更新**：`app/layout.tsx` — 用 `<Providers>` 包裹 children
- **新建**：`lib/cn/hooks.ts` — 从 `my-invest-global/frontend/src/api/hooks.ts` 移植

  移植的 hooks（base URL 改为 `/api/cn`，移除 Zustand auth 依赖）：

  Portfolio：
  - `useHoldings()`, `useHoldingsFiltered(filters)`, `usePortfolioMetrics()`, `usePortfolioBalance()`
  - `useSaveHoldings()`, `usePortfolioMetricsFiltered(filters)`, `usePortfolioSnapshots()`

  Stock：
  - `useOHLCV(code, days?)`, `useScarcity(code)`, `useStockNews(code, limit?)`

  Market：
  - `useMarketRegime()`, `useIndexOHLCV(code, days?)`, `useMarketTurnover(days?)`
  - `useMarketFundFlow(days?)`, `useSectorData()`

  Analysis：
  - `useLatestAnalysis()`, `useTriggerAnalysis()`

  Macro：
  - `useMacroState()`, `useSetMacroState()`, `useCapex()`

  Events/Misc：
  - `useSessionStatus()`, `useTradingDays()`, `useFilterOptions()`
  - `useReviewDiary(date?)`, `useSaveReviewDiary()`

# Out of Scope

- Plotly 图表组件（REQ-006）
- `axios` 依赖（改用原生 `fetch`，与 Next.js 更契合）

# Implementation Notes

- `staleTime: 300_000`（5 分钟，与 my-invest-global 对齐）
- 开发环境渲染 `<ReactQueryDevtools>`，生产环境不渲染
- hooks 均为 `'use client'` 边界内使用，无需 server-side import

# Acceptance Criteria

- `pnpm add @tanstack/react-query` 后 `pnpm typecheck` 通过
- `useHoldings()` 在 React 组件中调用，网络请求发往 `/api/cn/portfolio/holdings`
- 5 分钟内重复调用 `useHoldings()` 无新网络请求
