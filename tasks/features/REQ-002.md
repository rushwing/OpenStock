# Goal

创建 `app/api/cn/[...path]/route.ts`，作为 Next.js 到 Python FastAPI 后端的透明代理。支持 GET/POST/PUT/DELETE。服务端自动管理 Python JWT，客户端无感知。

# In Scope

- **新建**：`app/api/cn/[...path]/route.ts`
  - 读取 `PYTHON_BACKEND_URL` env var（服务端）
  - 读取 `CN_PASSPHRASE` env var，调用 `/api/auth/unlock` 获取 Python JWT
  - JWT 缓存于服务端内存（module-level singleton），5 分钟内复用
  - JWT 失效（401）时自动重新认证一次
  - 转发原始请求：path、query params、body、Content-Type
  - 复制响应：status code、body（streaming 支持）
- **新建**：`lib/cn/python-auth.ts`
  - `getPythonToken(): Promise<string>` — 获取或刷新 JWT
- **更新**：`.env` 添加 `PYTHON_BACKEND_URL=http://localhost:8000` 和 `CN_PASSPHRASE=`
- **更新**：`.env.example` 对应添加占位注释
- **Auth 守卫**：代理层校验 better-auth 会话（`auth.api.getSession()`）；未登录返回 401

# Out of Scope

- 客户端 React Query hooks（REQ-004）
- Python 后端本身的任何改动

# Implementation Notes

- `PYTHON_BACKEND_URL` 和 `CN_PASSPHRASE` 不加 `NEXT_PUBLIC_` 前缀，确保仅服务端可见
- AI 信号触发接口（`/api/analysis/run`）响应可能超过 60s，代理层设置 `fetch` timeout 为 120s
- Python JWT 默认有效期为 30 分钟（参考 my-invest-global 配置）；缓存使用 `Date.now()` 对比过期时间

# Acceptance Criteria

- `curl -H 'Cookie: <valid-session>' http://localhost:3000/api/cn/health` → `{"status": "ok"}`
- 未携带 better-auth 会话 → 401（不转发到 Python）
- Python 后端不可达时 → 502（不暴露内部错误堆栈）
- `pnpm typecheck` 对新文件无 type error
