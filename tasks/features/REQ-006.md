# Goal

创建深度分析页，提供 A 股个股的 OHLCV 图表、技术指标叠加、资金流向分析。引入 Plotly.js 作为图表引擎。

# In Scope

- **依赖安装**：`react-plotly.js`, `plotly.js`, `@types/plotly.js`
- **新建**：`app/(root)/cn/analysis/page.tsx`
- **新建**：`components/cn/DeepAnalysis.tsx`（从 Tab3DeepAnalysis.tsx 移植）

  核心功能：
  - 股票选择器（从持仓列表生成）
  - 时间范围选择（1M / 3M / 6M / 1Y）
  - K 线图（蜡烛图 + MA5/MA10/MA20 均线叠加）
  - MACD 子图（DIF / DEA / 柱状图）
  - RSI 子图
  - 资金流向图（5 日净流入）

- **重要**：所有 Plotly 组件通过 `next/dynamic(() => import('...'), { ssr: false })` 懒加载

# Out of Scope

- 稀缺度矩阵（scarcity matrix）展示（可选扩展）
- KG 知识图谱可视化

# Implementation Notes

Plotly SSR 兼容处理：

```typescript
const Plot = dynamic(
  () => import('react-plotly.js'),
  { ssr: false, loading: () => <div>图表加载中...</div> }
)
```

Plotly bundle 约 3MB，通过懒加载确保不影响首屏 LCP。

# Acceptance Criteria

- K 线图正确渲染（蜡烛颜色：红涨绿跌，符合 A 股习惯）
- Plotly 不出现在 `/_next/static/chunks/pages/` 的初始 bundle 中（用 `@next/bundle-analyzer` 验证）
- `pnpm typecheck` 无新增 type error
