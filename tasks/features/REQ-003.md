# Goal

完善 REQ-002 的 Auth 集成：确保 better-auth 会话与 Python JWT 之间的映射完整、安全，并处理 JWT 过期自动刷新场景。

# In Scope

- **完善**：`lib/cn/python-auth.ts` 的 JWT 刷新逻辑
  - Token 过期提前 60s 重新获取（避免请求中途 401）
  - 并发请求时防止多次调用 `/api/auth/unlock`（使用 Promise 锁）
- **测试**：`__tests__/cn/python-auth.test.ts`（使用 vitest mock fetch）
  - 测试 token 缓存
  - 测试并发请求不会触发多次 unlock
  - 测试 JWT 刷新触发时机

# Out of Scope

- 前端登录 UI（already in OpenStock）
- Python 后端的 auth 实现（不修改）

# Acceptance Criteria

- 登录用户访问 `/api/cn/portfolio/holdings` → HTTP 200 + 持仓数据
- 未登录用户 → 401（`{ "error": "Unauthorized" }`）
- 模拟 JWT 过期场景：代理层自动重试并返回正确数据（非 401）
- `pnpm test` 对新测试文件全部通过
