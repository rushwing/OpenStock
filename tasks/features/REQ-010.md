# Goal

补充大A相关的常量配置，使 TradingView 组件可以展示 A 股行情，并为 CN 搜索提供默认热门股票列表。

# In Scope

- **更新**：`lib/constants.ts`

  新增常量：
  ```typescript
  // A 股热门股票（Finnhub 格式）
  export const CN_POPULAR_STOCK_SYMBOLS = [
    '600519.SS',  // 贵州茅台
    '000858.SZ',  // 五粮液
    '601318.SS',  // 中国平安
    '000001.SZ',  // 平安银行
    '600036.SS',  // 招商银行
    '601166.SS',  // 兴业银行
    '600900.SS',  // 长江电力
    '601288.SS',  // 农业银行
    '600276.SS',  // 恒瑞医药
    '300750.SZ',  // 宁德时代
  ]

  // TradingView A 股热力图配置
  export const CN_HEATMAP_WIDGET_CONFIG = {
    dataSource: 'SSE50',
    blockColor: 'change',
    grouping: 'sector',
    ...（其他 field 与现有 HEATMAP_WIDGET_CONFIG 结构一致）
  }

  // TradingView A 股市场概览配置
  export const CN_MARKET_OVERVIEW_WIDGET_CONFIG = {
    // tabs: Financial(SSE:601318), Tech(SSE:688981), Consumer(SSE:600519)...
  }
  ```

- **更新**：`components/TradingViewWidget.tsx`（如需）：确认组件能处理 `SSE:` / `SZSE:` 前缀的 symbol

# Out of Scope

- 在大A页面实际使用 TradingView 组件（REQ-006/007 可酌情使用）

# Acceptance Criteria

- `CN_POPULAR_STOCK_SYMBOLS` 数组 length ≥ 10，所有代码格式为 `XXXXXX.SS` 或 `XXXXXX.SZ`
- `CN_HEATMAP_WIDGET_CONFIG.dataSource` 为 `'SSE50'` 或 `'CSI300'`
- `pnpm typecheck` 通过
