# Goal

更新 OpenStock 导航，加入大A功能入口，实现美股/大A的无缝切换。搜索功能根据当前市场上下文调用不同数据源。

# In Scope

- **更新**：`lib/constants.ts` 中 `NAV_ITEMS`

  新结构：
  ```typescript
  export const NAV_ITEMS = [
    // US 分组
    { href: '/', label: 'Dashboard', market: 'us' },
    { href: '/search', label: 'Search', market: 'us' },
    { href: '/watchlist', label: 'Watchlist', market: 'us' },
    // CN 分组
    { href: '/cn/portfolio', label: '持仓', market: 'cn' },
    { href: '/cn/analysis', label: '分析', market: 'cn' },
    { href: '/cn/signals', label: '信号', market: 'cn' },
    { href: '/cn/rebalance', label: '调仓', market: 'cn' },
    // 通用
    { href: '/api-docs', label: 'API Docs', market: 'both' },
  ]
  ```

- **更新**：`components/NavItems.tsx`
  - US 组和 CN 组之间加分隔线或视觉区分（badge 或颜色）
  - CN 组 label 用中文
  - 当前 market 组 active 样式更明显

- **更新**：`components/SearchCommand.tsx`
  - 当 pathname 以 `/cn` 开头时，搜索调用 Python 后端 `/api/cn/stock/search?q=`
  - 否则调用现有 Finnhub `searchStocks`

# Out of Scope

- 移动端 hamburger 菜单优化（现有结构不变）

# Acceptance Criteria

- 桌面端导航中 US 和 CN 分组有视觉区分
- 搜索框在 CN 页面下返回 A 股结果（代码为 6 位数字）
- 导航 active 状态正确：`/cn/*` 路由时 CN 组高亮，`/` 路由时 US 组高亮
- `pnpm typecheck` 对 NAV_ITEMS 类型无报错
