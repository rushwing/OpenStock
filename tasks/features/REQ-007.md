# Goal

创建 AI 信号页，展示 LangGraph + Claude 生成的 A 股投资信号，并支持手动触发信号生成。

# In Scope

- **新建**：`app/(root)/cn/signals/page.tsx`
- **新建**：`components/cn/Signals.tsx`（从 Tab4Signals.tsx 移植）

  核心功能：
  - 宏观红绿灯 + 弹性仓位目标（MacroPanel）
  - 仓位偏差仪表盘（RebalanceGauge）
  - 「触发分析」按钮（调用 `useTriggerAnalysis()`）
  - 信号列表（每条：代码、名称、composite_score、action_code 色块、三维评分条）
  - 加载状态（LangGraph 运行中提示）

- **关键**：`useTriggerAnalysis()` 调用**直连** Python 后端（`NEXT_PUBLIC_PYTHON_BACKEND_URL`），不走 Next.js 代理，避免 Vercel 10s 超时

# Out of Scope

- KG 子图可视化
- 信号历史记录对比

# Implementation Notes

信号生成的两条路径：

```
普通查询（useLatestAnalysis）
  浏览器 → /api/cn/analysis/latest → Python FastAPI（<5s）

触发新分析（useTriggerAnalysis）
  浏览器 → NEXT_PUBLIC_PYTHON_BACKEND_URL/api/analysis/run → Python FastAPI（30-120s）
```

第二条路径绕过 Next.js，需要 CORS 配置（Python 后端 `allow_origins` 已包含前端域名）。

`NEXT_PUBLIC_PYTHON_BACKEND_URL` 在 Vercel/树莓派部署时设置为 Python 后端的实际 URL（需同域或已配置 CORS）。

# Acceptance Criteria

- 触发分析后 UI 显示加载状态（spinner / 进度条）
- 信号返回后按 composite_score 降序展示
- `action_code` 颜色编码（strong_add=绿, hold=蓝, reduce=橙, stop_loss=红）
- 网络超时（Python 后端未响应）时显示友好错误而非白屏
