# Goal

创建调仓页，展示基于宏观状态的仓位目标偏差，以及 AI 生成的调仓建议。

# In Scope

- **新建**：`app/(root)/cn/rebalance/page.tsx`
- **新建**：`components/cn/Rebalance.tsx`（从 Tab5Rebalance.tsx 移植）

  核心功能：
  - 仓位偏差仪表盘（Plotly gauge chart：当前弹性仓位% vs 目标%）
  - 白马股 / 弹性股分组持仓（市值、占比）
  - 调仓建议列表（来自 `/api/portfolio/plan` 接口）
  - 调仓建议来源标注（强调 AI 建议仅供参考，最终操作由人工决定）

# Out of Scope

- 盘后总结填写（可后续扩展）

# Implementation Notes

调仓建议逻辑完全在 Python 后端（`api/routers/plan.py`），前端只做展示。

# Acceptance Criteria

- 仪表盘 gauge 正确显示偏差值（红/橙/绿颜色区分偏差程度）
- 调仓建议列表每行含 code, name, action, planned_qty
- 免责声明文字可见："以上建议由 AI 生成，仅供参考，不构成投资建议"
