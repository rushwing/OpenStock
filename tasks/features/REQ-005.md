# Goal

创建大A持仓总览页，对应 my-invest-global Tab1 Holdings 的核心功能：持仓列表、关键指标、宏观状态、过滤器。

# In Scope

- **新建**：`app/(root)/cn/portfolio/page.tsx`（`'use client'`，需 auth 保护）
- **新建**：`components/cn/tokens.ts`（从 `my-invest-global/frontend/src/tokens.ts` 移植颜色/字体 token）
- **新建**：`components/cn/primitives.tsx`（从 `primitives.tsx` 移植 Card, Mono, SectionTitle, StatusPill 等基础组件）
- **新建**：`components/cn/Portfolio.tsx`（从 Tab1Holdings.tsx 移植，精简为核心功能）

  核心功能：
  - 持仓表格（代码、名称、类别、成本价、现价、盈亏%、市值）
  - 总市值 / 总盈亏 KPI 卡片
  - 宏观红绿灯指示器（MacroPanel）
  - 用户/券商/板块过滤器（FilterBar）

# Out of Scope

- 盘前计划 / 盘后总结子视图（Tab1 的 VIEWS 切换，PHASE-004 可扩展）
- Session Timer 倒计时（可选，后期加）
- Plotly 持仓饼图（PHASE-003 随 analysis 一起引入 Plotly）

# Implementation Notes

- 组件标注 `'use client'`，使用 `useHoldings()` 和 `usePortfolioMetrics()`
- 颜色 token 从 CN tokens 读取（不混用 OpenStock 的 teal 主色，视觉区分两个市场）
- 路由保护：复用 OpenStock 现有的 `auth.api.getSession()` middleware

# Acceptance Criteria

- 访问 `/cn/portfolio` → 持仓表格渲染，至少 1 行数据（需 Python 后端有持仓）
- 无持仓数据时显示空状态提示而非白屏
- MacroPanel 显示 green/yellow/red 之一
- `pnpm typecheck && pnpm lint` 通过
